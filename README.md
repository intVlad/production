# Walkthrough: Production MVP (Cloud Deployed)

Цей документ підсумовує результати розробки та деплою Production MVP.

## 🚀 Що було зроблено

Ми перетворили локальний прототип на повноцінний хмарний застосунок:
1. **Деплой Backend:** Spring Boot API успішно розміщено на Render.
2. **База даних:** Здійснено міграцію з локальної in-memory бази (H2) на хмарну PostgreSQL від Neon.
3. **Деплой Frontend:** Клієнтська частина (Vanilla JS/HTML/CSS) задеплоєна на Vercel.
4. **QR-коди:** Додано генерацію QR-кодів (маршрутних листів) при запуску виробу у виробництво для швидкого доступу працівників.
5. **Динамічний API:** Фронтенд тепер автоматично перемикається між локальним та продакшен сервером.

## 🧪 Що можна протестувати прямо зараз (End-to-End Flow)

Зайдіть на [https://production-mvp.vercel.app](https://production-mvp.vercel.app) і спробуйте:
1. **Додати працівника:** Створіть нового працівника у відповідній формі.
2. **Створити Модель:** Створіть нову модель (наприклад, "Стіл") з етапами ("Нарізка", "Збірка").
3. **Запустити у виробництво:** Натисніть кнопку запуску біля вашої моделі — ви побачите модальне вікно з **QR-кодом**.
4. **Роль Працівника:** Відскануйте QR-код (або натисніть на нього у демо-режимі), щоб потрапити на сторінку виконавця, де можна взяти етап у роботу, повідомити про нестачу матеріалів або завершити його.

## ✅ Результати валідації
- **База Даних:** Зв'язок із Neon PostgreSQL успішний. Таблиці створюються автоматично завдяки Hibernate.
- **API:** Render автоматично прив'язався до порту `$PORT` і успішно обробляє HTTP запити.
- **Frontend:** Vercel успішно роздає статику та спілкується з бекендом без помилок CORS (налаштовано у Spring Boot).
